# Смотри как идём

Маршруты в движении: ставите точки на карте, маршрут сам прокладывается по улицам, а приложение собирает вертикальное видео 1080×1920 с анимацией пунктира, подпрыгивающими пинами и карточками с фото и подписями.

Открыть: https://e1so1.github.io/smotri/

Работает и как мини-приложение в Telegram.

## Данные и сервисы

- Карта: [OpenFreeMap](https://openfreemap.org) © [OpenMapTiles](https://www.openmaptiles.org/) © [участники OpenStreetMap](https://www.openstreetmap.org/copyright) — отрисовывается в собственном стиле прямо в браузере.
- Маршруты по улицам: OSRM и Valhalla (серверы FOSSGIS).
- Поиск и адреса: Photon (komoot) и Nominatim (OpenStreetMap).

Всё работает в браузере, без ключей и без своего сервера.
